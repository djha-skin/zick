zick is a Common Lisp program, built with Roswell and ocicl. You build the zick executable yourself; there are no prebuilt binaries yet.

Prerequisites

  • A recent SBCL — zick is developed against SBCL 2.x
  • Roswell, for ros and ros build
  • ocicl, for dependencies

Building from Source

Clone the repository:

git clone https://github.com/djha-skin/zick.git
cd zick

Install the dependencies (this uses the ocicl.csv manifest in the repository root):

ocicl install

Build the executable:

./scripts/build

The build script bakes the large heap and control-stack sizes zick needs for big repository resolutions into the binary, so no wrapper or environment variables are required at run time. The result is ./com.djhaskin.zick in the project root. You can rename it to zick and put it on your PATH:

ln -s "$PWD/com.djhaskin.zick" ~/.local/bin/zick

To use the command names in this manual without a PATH change, the examples that follow assume zick is on your PATH. (If yours is still at ./com.djhaskin.zick, substitute it in.)

Checking the Installation

Run zick with no arguments; it prints a short usage summary:

zick

And zick help prints the full CLIFF help page: how options are gathered, the alias table, and the list of subcommands.
